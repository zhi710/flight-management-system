## 1. 产品概述

### 1.1 产品定位

面向普通旅客的航班服务网站，提供航班查询、在线预订、值机选座、行程管理等一站式出行服务。对标携程航班模块、航旅纵横等产品。

### 1.2 目标用户

| 用户画像 | 特征 | 核心需求 |
|---------|------|---------|
| 商务旅客 | 出行频繁，价格敏感度低，时间敏感 | 快速订票、改签灵活、行程提醒 |
| 休闲旅客 | 提前规划，价格敏感，频次低 | 比价、特价、退改政策清晰 |
| 常旅客 | 航司会员，积分敏感 | 会员权益、里程累积、优先服务 |

### 1.3 设计目标

| 指标 | 目标值 |
|------|-------|
| 首屏加载 | < 1.5 秒 |
| 搜索到结果 | < 2 秒 |
| 下单转化率 | > 8% |
| 移动端占比 | > 60% |
| 用户满意度 (NPS) | > 50 |

### 3.3 机票预订

#### 3.3.1 预订流程

```
选择航班 → 填写旅客信息 → 选择附加服务 → 确认订单 → 支付 → 预订成功
```

#### 3.3.2 旅客信息填写

| 字段 | 必填 | 说明 |
|------|------|------|
| 姓名 | 是 | 与证件一致，支持姓名生僻字输入 |
| 证件类型 | 是 | 身份证 / 护照 / 港澳通行证 / 台胞证 / 其他 |
| 证件号码 | 是 | 自动校验格式 |
| 性别 | 是 | 男 / 女 |
| 出生日期 | 是 | 儿童/婴儿必填 |
| 手机号 | 是 | 接收出票通知和航班变动 |
| 邮箱 | 否 | 接收电子行程单 |
| 常旅客号 | 否 | 自动累积里程 |

- 支持从历史旅客中快速选择
- 支持拍照识别证件自动填充
- 多人出行时支持批量填写

#### 3.3.3 附加服务

| 服务类型 | 说明 | 优先级 |
|---------|------|-------|
| 额外行李 | 购买额外托运行李额度（10kg/20kg/30kg） | P0 |
| 航空保险 | 航意险、延误险、综合险 | P0 |
| 预选座位 | 付费选择靠窗/靠走道/前排座位 | P1 |
| 机上餐食 | 预订特殊餐食（素食、清真等），详见 SSR 3.3.4 | P2 |
| 接送机 | 预约接送机服务 | P2 |
| 休息室 | 购买贵宾休息室使用权 | P2 |

#### 3.3.4 特殊旅客服务(SSR)

在旅客信息填写完成后、订单确认前，为每位旅客单独选择 SSR 服务：

| 服务类别 | 可选项目 | 费用说明 |
|---------|---------|---------|
| 特殊餐食 | 素食餐 / 清真餐 / 儿童餐 | 免费 |
| 轮椅服务 | 客梯轮椅 / 停机坪轮椅 / 客舱轮椅 | 免费 |
| 无人陪伴儿童 | 5-12 岁单飞陪同服务 | ¥200-¥500 |
| 宠物运输 | 随行入客舱 / 托运 / 有氧货舱 | ¥500-¥1000 |
| 额外行李 | 5kg / 10kg / 20kg 额度 | ¥50-¥200/份 |

- SSR 按旅客维度选择，同一订单不同旅客可选不同服务
- 已选 SSR 在订单详情页展示（见 3.4.2）
- 部分 SSR（无人陪伴儿童、宠物运输）需航司审核，审核进度通过通知中心推送

### 3.4 行程管理

#### 3.4.1 我的订单

| 订单状态 | 筛选标签 |
|---------|---------|
| 待支付 | 带支付倒计时 |
| 已出票 | 可操作：改签、退票、值机 |
| 已完成 | 历史行程 |
| 已取消 | 已取消/已退票 |

订单卡片展示：航班号、日期、时刻、航线、状态、操作按钮。
订单卡片针对自动改签订单展示「已改签」标签，标注改签后新航班信息。

#### 3.4.2 订单详情

- 航班信息（含实时动态）
- 旅客信息
- 费用明细
- 退改签规则
- 附加服务信息
- SSR 特殊服务列表（如已选择）
- 操作按钮：改签、退票、值机、开发票

**自动改签**：当原航班因航司原因取消时，系统自动为旅客改签至替代航班。
- 订单详情顶部展示提示：「本订单由原航班 XXX（原航班号）自动改签」
- 展示原航班号链接，点击可查看原订单详情
- 自动改签后旅客会收到实时 WebSocket 通知，含新航班信息
- 自动改签含免费和付费两种策略，付费策略需在通知中确认支付

#### 3.4.3 改签

```
选择要改签的航段 → 选择新航班 → 确认改签费用 → 支付差价/手续费 → 改签成功
```

- 展示可改签航班列表（与搜索结果类似）
- 自动计算改签费用差价
- 改签后更新订单信息

#### 3.4.4 退票

```
选择退票航段 → 确认退票原因 → 计算退款金额 → 确认退票 → 退款到账
```

- 展示退票手续费及退款金额
- 支持部分退票（多人订单中部分旅客退票）
- 退款原路返回，1-7 个工作日到账

### 3.9 通知中心

#### 3.9.1 通知入口

顶部导航栏新增通知铃铛图标，展示未读通知数量角标。点击铃铛展开通知面板。

#### 3.9.2 通知类型

| 通知类型 | 内容 | 触发条件 |
|---------|------|---------|
| 系统通知 | 系统维护、政策变更等公告 | 后台发布 |
| 航班变动 | 航班延误 / 取消 / 登机口变更 | 航班状态变更时 |
| 改签结果 | 自动改签成功通知，含新航班信息 | 系统自动改签完成 |
| 值机状态 | 值机开放 / 值机成功 | 值机状态变更 |

#### 3.9.3 通知面板

- 通知列表分页加载，按时间倒序排列
- 未读通知有蓝色圆点标记
- 点击通知跳转至相关详情页（订单页 / 航班动态）
- 「全部已读」按钮一键标记所有通知为已读
- 支持单条删除

#### 3.9.4 实时通知架构（WebSocket）

WebSocket 连接在用户登录后建立，断线后自动重连。

```
通知链路：后端事件 → WebSocket 推送 → 前端接收 → ElNotification 弹窗 + 写入通知列表
```

- 新通知到达时触发 Element Plus `ElNotification` 弹窗（右上角弹出，3 秒自动关闭）
- 弹窗内容：通知标题 + 摘要 + 时间
- 通知列表实时刷新，无需手动刷新页面
- 所有后端发送的短信/邮件通知同步通过 WebSocket 推送至通知中心
