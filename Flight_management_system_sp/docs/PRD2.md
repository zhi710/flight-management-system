## 1. 产品概述

### 1.1 产品定位

面向航空公司及机场运营方的内部管理系统，涵盖航班调度、旅客服务、机组管理、运营监控、客票管理等核心业务，实现航班运营全流程数字化管理。

### 1.2 目标用户

| 用户角色 | 职责 | 核心诉求 |
|---------|------|---------|
| 航班调度员 | 航班计划编排、时刻调整 | 高效排班、冲突检测 |
| 地勤人员 | 值机、登机口管理、行李处理 | 快速操作、状态同步 |
| 机组管理员 | 飞行员/乘务员排班、资质管理 | 自动排班、合规检查 |
| 运营总监 | 全局监控、数据决策 | 实时大屏、报表分析 |
| 客服人员 | 旅客咨询、改签退票 | 快速查询、一键操作 |
| 系统管理员 | 系统配置、权限管理 | 灵活配置、安全管控 |

### 1.3 设计目标

| 指标 | 目标值 |
|------|-------|
| 核心操作效率 | 较现有系统提升 40% |
| 系统响应时间 | 交互操作 < 500ms |
| 并发用户 | 支持 5000 在线用户 |
| 系统可用性 | 99.9% |
| 培训成本 | 新用户 2 小时上手核心功能 |

4. 为每位受影响旅客创建自动改签记录，状态初始为"待确认"
5. 管理员进入IROPS详情查看改签建议
