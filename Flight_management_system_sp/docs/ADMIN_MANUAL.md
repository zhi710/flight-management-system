- 系统管理：用户管理、角色权限、基础数据、操作日志、系统配置

## 1. 系统登录

### 1.1 登录

打开后台管理地址，进入登录页面。输入管理员用户名和密码，点击「登录」。

**示例：**

| 字段 | 值 |
|------|-----|
| 用户名 | `admin` |
| 密码 | `admin123` |

> 若系统开启了多因素认证（MFA），输入密码后会弹出验证码输入框，输入一次性验证码后完成登录。

### 1.2 登录成功

登录成功后自动跳转到**监控大屏**页面。页面左侧为导航菜单，右侧顶部为操作栏（收起侧边栏、全屏切换、个人信息）。

## 2. 监控大屏

路径：`/dashboard`

运营总览首页，实时展示今日航班运行情况。

### 2.1 统计卡片

页面顶部 5 张统计卡片：

| 卡片 | 含义 |
|------|------|
| 计划航班 | 今日计划执行的总航班数 |
| 已执行 | 今日已正常执行的航班数 |
| 延误航班 | 今日发生延误的航班数 |
| 取消航班 | 今日已取消的航班数 |
| 今日旅客 | 今日所有航班承运旅客总数 |

### 2.2 图表区域

- **航班状态分布** — 饼图展示各状态航班占比（正常/延误/取消/备降/返航）
- **延误原因分析** — 柱状图展示延误原因分布（天气/流控/机械/其他）

### 2.3 实时航班列表

表格展示当前时刻附近的航班信息，点击「详情」可跳转至对应航班页面。

### 2.4 事件时间线

最新操作事件的动态时间线，如"航班 CA1234 发生延误，预计 14:30 起飞"。

### 2.5 告警铃铛

操作步骤：
1. 在系统任意页面，右上角可看到一个铃铛图标(🔔)
2. 当有不正常航班、系统告警时，铃铛上会显示红色未读数字角标
3. 点击铃铛可查看最近告警列表
4. 点击任意告警可跳转到告警中心详情页
5. 当航班被处理为不正常状态时，系统会弹窗实时通知管理员

## 3. 航班调度

### 3.1 航班计划管理

路径：`/flights`

#### 3.1.1 查询航班

支持按日期、航线、状态、关键字（航班号/航空公司）筛选。

**示例：** 查询 2026-06-23 北京→上海的所有航班：
1. 日期选择 `2026-06-23`
2. 出发城市输入 `北京`，到达城市输入 `上海`
3. 点击「查询」

#### 3.1.2 创建航班

点击「新增航班」按钮，填写以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 航班号 | 二字码+数字 | `CA1234` |
| 日期 | 航班执行日期 | `2026-06-23` |
| 出发机场 | 从基础数据中选择 | `PEK-北京首都` |
| 到达机场 | 从基础数据中选择 | `SHA-上海虹桥` |
| 计划起飞时间 | 格式 HH:mm | `08:00` |
| 计划到达时间 | 格式 HH:mm | `10:30` |
| 机型 | 从基础数据中选择 | `A330` |
| 机号 | 飞机注册号 | `B-6090` |
| 航班类型 | 国内/国际/地区 | `国内` |
| 备注 | 可选 | `每日一班` |

#### 3.1.3 编辑/删除

- 在航班列表中点击「编辑」修改航班信息
- 点击「删除」确认后删除航班（仅可删除未执行航班）

#### 3.1.4 批量操作

勾选多个航班，点击「批量取消」可一次性取消多个航班。

### 3.2 时刻表查看

路径：`/flights/schedule`

三种视图模式：

| 视图 | 说明 |
|------|------|
| 日历视图 | 表格展示某日航班，含航班号、航线、时间、状态 |
| 时间线视图 | 按小时分组，横向展示各时段航班分布 |
| 航线视图 | 按航线聚合展示（开发中） |

使用上方的日期范围和航线筛选条件缩小查询范围。

### 3.3 非正常航班处理

在航班列表中点击「非正常」按钮，处理以下情况：

| 类型 | 说明 | 必填字段 |
|------|------|----------|
| 延误 | 航班晚于计划时间起飞 | 预计起飞时间、原因 |
| 取消 | 航班取消不执行 | 原因 |
| 备降 | 航班备降其他机场 | 备降机场、原因 |
| 返航 | 航班起飞后返回起飞机场 | 原因 |

勾选「通知旅客」后，系统会自动发送短信/邮件通知受影响旅客。

**示例：** 因天气原因 CA1234 延误至 11:00，操作步骤：
1. 找到 CA1234 航班，点击「非正常」
2. 选择「延误」
3. 预计起飞时间填入 `11:00`
4. 原因选择 `天气原因`
5. 勾选「通知旅客」
6. 点击「确认」

### 3.4 不正常航班管理（IROPS）

进入运营监控 > 不正常航班
操作步骤：
1. 页面展示所有不正常航班操作记录，支持按类型（延误/取消/备降/返航）、状态筛选
2. 点击「旅客」按钮查看受该航班影响的所有旅客清单
3. 点击「改签」按钮查看自动改签结果
   - 航班取消时系统自动查找同航线替代航班
   - 自动为每位旅客创建改签记录
   - 管理员可「确认」或「拒绝」每条自动改签
4. 手动改签：在受影响旅客对话框中，点击「改签」可手动选择新航班和舱位
5. 点击「通知」按钮可向所有受影响旅客发送WebSocket实时通知

## 4. 旅客服务

### 4.1 旅客查询

路径：`/passengers`

可通过姓名、证件号、航班号、PNR（预订编号）、手机号查询旅客信息。

查询结果展示旅客姓名、性别、证件类型/号码、手机号、会员等级、是否黑名单、最近行程等。

**示例：** 查询证件号为 `110101199001011234` 的旅客：
1. 证件号输入 `110101199001011234`
2. 点击「查询」

### 4.2 值机管理

路径：`/checkin`

#### 4.2.1 查询航班

输入航班 ID（如 `F202606230001`），查询该航班的旅客值机状态。

页面展示航班基本信息：航班号、出发/到达机场、值机状态（开放/关闭）。

#### 4.2.2 开放/关闭值机

- 点击「开放值机」允许旅客在线办理值机
- 点击「关闭值机」停止办理值机手续

> 一般航班起飞前 24 小时开放值机，起飞前 30 分钟关闭。

#### 4.2.3 手动值机

为未值机旅客手动分配座位：
1. 点击旅客所在行的「手动值机」
2. 选择座位排号（1-60）和列号（A-F）
3. 点击「确认」

**示例：** 为旅客张三分配 12A 座位：
1. 找到张三，点击「手动值机」
2. 排号选 `12`，列号选 `A`
3. 点击「确认」

#### 4.2.4 自动分配座位

点击「自动分配座位」，系统为所有未值机旅客自动分配座位。

#### 4.2.5 取消值机

已值机的旅客，点击「取消值机」可撤销其值机和座位。

#### 4.2.6 导出名单

点击「导出名单」下载 Excel 格式的旅客值机名单。

### 4.3 登机口管理

路径：`/gates`

#### 4.3.1 查询登机口分配

选择日期和航站楼（T1/T2/T3），查看当日登机口分配情况。

#### 4.3.2 分配登机口

1. 点击「分配登机口」
2. 输入航班 ID
3. 选择起止时间
4. 点击「确认」

**示例：** 为航班 CA1234 分配 T2 航站楼 12 号登机口：
1. 选择航站楼 `T2`
2. 找到 12 号登机口，点击「分配」
3. 航班 ID 输入 `F202606230001`
4. 时间选择 `08:00 - 11:00`
5. 点击「确认」

#### 4.3.3 变更登机口

已分配的登机口如需调整，点击「变更」修改时间和航班。

### 4.4 特殊旅客服务(SSR)

路径：`/passengers/ssr`

#### 4.4.1 查看SSR申请

选择航班后，展示该航班所有SSR申请列表。支持按状态筛选：待处理/已通过/已拒绝。

每条SSR显示：旅客姓名、SSR代码（如WCHR轮椅）、服务名称。

#### 4.4.2 处理SSR申请

点击「通过」或「拒绝」按钮处理SSR申请。

## 5. 机组管理

### 5.1 机组排班

路径：`/crew/schedule`

#### 5.1.1 查看排班

选择日期范围、部门、资质（如 A330 机型资质），查询机组排班表。

#### 5.1.2 手动添加排班

1. 点击「新增排班」
2. 输入机组人员 ID、航班 ID、角色（机长/副驾驶/乘务长/乘务员）、日期
3. 点击「确认」

**示例：** 为机组人员 C001 安排 2026-06-23 执飞 CA1234：
1. 点击「新增排班」
2. 机组ID 输入 `C001`
3. 航班ID 输入 `F202606230001`
4. 角色选择 `机长`
5. 日期选择 `2026-06-23`
6. 点击「确认」

#### 5.1.3 自动排班

1. 点击「自动排班」
2. 输入日期范围
3. 在文本框中输入需排班航班 ID（每行一个）
4. 点击「生成」

系统会根据机组资质和工时限制自动分配人员。

#### 5.1.4 删除排班

点击「删除」确认后移除该排班记录。

### 5.2 机组动态

路径：`/crew/dynamics`

实时查看机组人员当前状态。顶部统计卡片展示：

| 状态 | 说明 |
|------|------|
| 飞行中 | 正在执行飞行任务的机组人数 |
| 待命 | 处于待命状态的机组人数 |
| 休息 | 处于休息期的机组人数 |
| 培训 | 正在参加培训的机组人数 |

下方表格展示每人详情：姓名、状态、当前/最近航班、位置、下次任务、本月飞行小时数。

### 5.3 机组合规

路径：`/crew/compliance`

#### 5.3.1 合规预警卡片

顶部展示合规预警卡片：飞行超时预警数、资质到期预警数。

#### 5.3.2 预警列表

列表展示所有合规预警详情：
- 飞行超时：近30天累计超过100小时（CAAC规定上限）
- 资质到期：资质证书将在30天内到期

超限预警会通过WebSocket实时推送到管理端。

## 6. 客票管理

### 6.1 订座管理

路径：`/tickets/bookings`

输入 PNR、旅客姓名或航班号查询订单。

点击「详情」查看订单完整信息，包括乘机人、航段、舱位、票价、状态、联系信息等。

**示例：** 查询 PNR 为 `SKYABC` 的订单：
1. PNR 输入 `SKYABC`
2. 点击「查询」
3. 点击「详情」查看完整信息

### 6.2 票价管理

路径：`/tickets/fares`

#### 6.2.1 查看票价

列表展示所有票价规则：航空公司、出发/到达城市、舱位等级（经济舱/商务舱/头等舱）、票价、税费、有效期、状态。

#### 6.2.2 新增票价

1. 点击「新增票价」
2. 填写以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 航空公司 | 二字码 | `CA` |
| 出发机场 | IATA 代码 | `PEK` |
| 到达机场 | IATA 代码 | `SHA` |
| 舱位等级 | 经济/商务/头等 | `经济舱` |
| 票价 | 不含税费 | `1200.00` |
| 税费 | 税费金额 | `50.00` |
| 生效日期 | 价格生效时间 | `2026-06-01` |
| 失效日期 | 价格失效时间 | `2026-12-31` |

#### 6.2.3 编辑/删除

点击「编辑」修改票价信息，点击「删除」移除该票价规则。

### 6.3 退改管理

路径：`/tickets/refunds`

两个标签页：**退票申请**和**改签申请**。

#### 6.3.1 退票审批

退票列表展示：退票编号、订单号、旅客姓名、航班号、退款金额、手续费、原因、状态。

点击「批准」或「拒绝」处理退票申请。

**示例：** 处理旅客李四的退票申请：
1. 在"退票申请"标签页找到李四的记录
2. 查看退款金额和手续费
3. 如符合规定，点击「批准」→「确认」
4. 如不符合规定，点击「拒绝」→ 填写拒绝原因 →「确认」

#### 6.3.2 改签审批

改签列表展示：改签编号、订单号、旅客姓名、原航班、新航班、改签费、差价、状态。

操作同样为「批准」或「拒绝」。

## 7. 运营监控

### 7.1 告警中心

路径：`/alerts`

#### 7.1.1 筛选告警

| 筛选条件 | 选项 |
|----------|------|
| 告警级别 | 紧急/重要/一般/提示 |
| 状态 | 待处理/已解决 |

#### 7.1.2 处理告警

点击告警后的「处理」按钮，确认后告警状态变为"已解决"。

顶部统计卡片展示紧急告警数、待处理数、已解决数，便于优先处理重要告警。

### 7.2 统计概览

路径：`/statistics`

统计概览支持按**维度**（航班/旅客/收入/服务）和**时间范围**进行数据聚合分析。

| 维度 | 说明 |
|------|------|
| 航班 | 各航线航班量、正常率等 |
| 旅客 | 旅客运输量、客座率等 |
| 收入 | 各航线收入、结算数据等 |
| 服务 | 投诉率、满意度等 |

可选择按天/周/月分组展示，图表和表格联动更新。

**示例：** 查看本月各航线收入情况：
1. 维度选择「收入」
2. 日期范围选择 `2026-06-01` 至 `2026-06-23`
3. 分组选择「按周」
4. 查看柱状图和明细表

### 7.3 地面保障

路径：`/ops/ground-support`

#### 7.3.1 保障概览

顶部展示今日保障概览：总航班数、正常保障数、保障延误数、准点率。

#### 7.3.2 保障记录

表格展示所有地面保障记录，支持按航班号、日期、状态筛选。

每条保障记录包含15个标准节点（推出、滑出、客梯车等）。

点击「完成」按钮标记该保障节点已完成（自动记录实际时间并计算延误）。

## 8. 报表中心

### 8.1 运营报表

路径：`/reports/operation`

#### 8.1.1 生成报表

| 报表类型 | 说明 |
|----------|------|
| 日报 | 每日航班执行情况汇总 |
| 延误报表 | 延误航班明细及原因分析 |
| 旅客报表 | 旅客运输量、客座率分析 |
| 机组报表 | 机组执飞情况汇总 |
| 机场报表 | 各机场运营情况汇总 |

选择报表类型和日期范围，点击「生成报表」。

#### 8.1.2 导出报表

生成报表后，可点击「导出 Excel」或「导出 PDF」下载。

**示例：** 导出 2026 年 6 月的延误报表：
1. 报表类型选择「延误报表」
2. 日期范围选择 `2026-06-01` 至 `2026-06-30`
3. 点击「生成报表」
4. 点击「导出 Excel」

## 9. 系统管理

### 9.1 用户管理

路径：`/system/users`

管理后台系统的所有操作员账户。

#### 9.1.1 创建用户

1. 点击「新增用户」
2. 填写以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 用户名 | 登录账号 | `zhangsan` |
| 姓名 | 真实姓名 | `张三` |
| 手机号 | 联系电话 | `13800138000` |
| 邮箱 | 电子邮箱 | `zhangsan@skyops.com` |
| 角色 | 选择一个或多个角色 | `调度员` |
| 密码 | 初始登录密码 | `Pass1234` |

> 角色决定了该用户可访问的菜单和可执行的操作。

#### 9.1.2 编辑/禁用/重置密码

- **编辑**：修改用户基本信息
- **启用/禁用**：禁用后该用户无法登录系统
- **重置密码**：将用户密码重置为初始值

### 9.2 角色权限

路径：`/system/roles`

#### 9.2.1 系统预置角色

| 角色 | 说明 |
|------|------|
| 管理员 | 所有权限，包括系统管理 |
| 调度员 | 航班调度、机组管理相关权限 |
| 值机员 | 值机管理、登机口管理权限 |
| 客服 | 旅客查询、订座管理、退改管理 |
| 查看者 | 仅有查看权限，无增删改操作 |

#### 9.2.2 创建角色

1. 点击「新增角色」
2. 填写角色名称、角色编码、描述
3. 勾选该角色拥有的权限（权限以功能模块的原子操作粒度划分）

**示例：** 创建一个"航班调度员"角色，仅允许航班和机组相关操作：
1. 名称：`航班调度员`
2. 编码：`FLIGHT_DISPATCHER`
3. 勾选权限：航班计划(查看/创建/编辑/删除)、时刻表(查看)、机组排班(查看/创建/删除)、机组动态(查看)
4. 点击「确认」

#### 9.2.3 删除角色

点击「删除」移除不再使用的角色（需确认）。

### 9.3 基础数据

路径：`/system/master-data`

管理系统运行所需的基础编码数据。支持 5 种数据类型：

| 数据类型 | 字段 | 示例 |
|----------|------|------|
| 机场 | 代码、名称、城市、国家 | `PEK`、`北京首都国际机场`、`北京`、`中国` |
| 航线 | 出发、到达、距离(km) | `PEK-SHA`、`北京→上海`、`1178` |
| 机型 | 代码、名称、制造商、座位数 | `A330`、`空客A330`、`Airbus`、`300` |
| 机队 | 机号、机型、状态 | `B-6090`、`A330`、`运营中` |
| 部门 | 编码、名称、负责人 | `CREW_DEPT`、`机组部`、`李经理` |

> 航班计划中的机场、机型、机号等选择项均来自基础数据，请确保基础数据先录入再创建航班。

**示例：** 添加机场"上海浦东国际机场"：
1. 选择标签页「机场」
2. 点击「新增」
3. 代码输入 `PVG`
4. 名称输入 `上海浦东国际机场`
5. 城市输入 `上海`
6. 国家输入 `中国`
7. 点击「确认」

### 9.4 操作日志

路径：`/system/logs`

记录所有管理员的操作行为，用于审计和追溯。

支持按操作人、模块、操作类型、时间范围筛选。

日志条目包括：操作人、所属模块、操作类型、操作对象、操作详情（可悬停查看完整信息）、IP 地址、操作时间。

**示例：** 查询张三在 2026-06-23 的所有操作：
1. 操作人输入 `张三`
2. 日期范围选择 `2026-06-23`
3. 点击「查询」
4. 查看操作记录，如"张三 修改了航班 CA1234 的起飞时间"

### 9.5 系统配置

路径：`/system/config`

全局参数配置，修改后即时生效。

#### 9.5.1 值机设置

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 值机开放时间 | 起飞前多少小时开放值机 | `24` |
| 登机截止时间 | 起飞前多少分钟关闭登机 | `15` |

#### 9.5.2 退改规则

| 参数 | 说明 |
|------|------|
| 起飞前 4 小时退票费率 | 如 `10` 表示收取票价 10% 手续费 |
| 起飞前 2 小时退票费率 | 如 `20` 表示收取票价 20% 手续费 |
| 起飞后退票费率 | 如 `50` 表示收取票价 50% 手续费 |

**示例：** 设置退票规则：
1. 起飞前 4 小时退票费率输入 `10`
2. 起飞前 2 小时退票费率输入 `20`
3. 起飞后退票费率输入 `50`
4. 点击「保存」

#### 9.5.3 通知模板

- **短信延误通知模板**：发送给旅客的延误短信内容模板
- **邮件电子客票模板**：发送给旅客的电子客票邮件内容模板
