## 一、系统概述

SkyTrip 天行航空旅客端是一个基于 Web 的航班管理系统，为旅客提供从航班搜索、机票预订、在线支付到值机办理的全流程服务。

**主要功能模块：**

| 模块 | 说明 |
|------|------|
| 航班搜索 | 按出发地、目的地、日期搜索航班，支持筛选和排序 |
| 机票预订 | 选择舱位、填写旅客信息、提交订单 |
| 在线支付 | 支持微信、支付宝、银行卡、信用卡等多种支付方式 |
| 订单管理 | 查看订单列表、订单详情、取消、改签、退票 |
| 在线值机 | 起飞前24小时内办理值机，可视化选座 |
| 航班动态 | 实时查询航班状态，订阅动态推送 |
| 会员中心 | 个人信息、里程管理、常用旅客管理 |
| 帮助中心 | FAQ查询、投诉建议 |

**技术栈：** Vue 3 + TypeScript + Element Plus + Pinia + Vue Router

## 二、账户管理

### 2.1 用户注册

**入口：** 登录页底部 "还没有账户？立即注册"

**操作步骤：**

1. 输入 **手机号码**（11位中国大陆手机号）
2. 点击 **"获取验证码"**，输入收到的6位短信验证码
3. （选填）输入 **姓名**
4. 输入 **密码**（8-20位，必须包含字母和数字）
5. 再次输入密码进行 **确认**
6. 勾选 **"我已阅读并同意《服务条款》和《隐私政策》"**
7. 点击 **"注册"** 按钮

> 注册成功后自动跳转至首页。

### 2.2 用户登录

**入口：** 访问系统任意页面，未登录时自动跳转至登录页

**支持两种登录方式：**

#### 密码登录（默认）

1. 输入手机号码
2. 输入登录密码
3. （如需要）输入图形验证码
4. 点击 **"登录"**

#### 验证码登录

1. 切换到 **"验证码登录"** 标签
2. 输入手机号码
3. 点击 **"获取验证码"**，输入6位短信验证码
4. 点击 **"登录"**

> 登录成功后跳转至首页。验证码60秒内有效，获取按钮在倒计时期间不可点击。

### 2.3 实时通知功能

操作说明：
1. 登录后，页面右上角导航栏会出现铃铛图标
2. 当有新的通知时（航班变动、改签结果），铃铛上会显示红色数字角标
3. 点击铃铛展开通知面板，可查看所有历史通知
4. 点击「全部已读」可一键标记所有通知
5. 关键通知会同时弹出系统窗口提醒

## 三、首页

登录后进入首页，页面分为四个区域。

### 3.1 航班搜索

页面顶部蓝色横幅区域，提供完整的航班搜索表单。

**操作步骤：**

1. **选择行程类型：** 单程 / 往返（往返会显示返程日期输入框）
2. **填写出发城市：** 输入城市名称或机场代码（如 "北京" 或 "PEK"）
3. **填写到达城市：** 同上
4. **选择出发日期：** 点击日期选择器，不可选择过去日期
5. **（往返）选择返程日期：** 不早于出发日期
6. **设置旅客人数：** 点击旅客输入框，弹出面板设置：
   - 成人（≥12岁）：最少1人，最多9人
   - 儿童（2-12岁）：最多9人
   - 婴儿（<2岁）：最多9人
7. **选择舱位等级：** 经济舱 / 公务舱 / 头等舱
8. **（可选）勾选 "仅看直飞"**
9. 点击 **"搜索航班"** 按钮

> 点击出发和到达城市之间的 ⇄ 按钮可快速交换两个城市。

### 3.2 热门航线

搜索区域下方展示热门航线卡片，每张卡片显示：

- 出发城市 → 到达城市
- 最低票价
- 航班日期

**点击任意热门航线卡片** → 自动跳转到搜索结果页，出发地和目的地已自动填入，日期默认为当天。

### 3.3 特价机票

热门航线下方展示特价机票卡片，每张卡片显示：

- 出发城市 → 到达城市
- 特价价格
- 航班日期和航空公司

**点击任意特价机票卡片** → 直接跳转到该航班的详情页，可查看详情并预订。

## 四、航班搜索与预订

### 4.1 搜索结果页

**路径：** 顶部导航 → 机票搜索，或首页搜索后自动跳转

**页面布局：**

#### 顶部搜索栏

紧凑版搜索栏，可修改出发地、目的地、日期后点击 **"搜索"** 重新查询。

#### 筛选与排序

| 功能 | 说明 |
|------|------|
| 仅直飞 | 勾选后只显示直飞航班 |
| 舱位等级 | 切换经济舱/公务舱/头等舱，自动重新搜索 |
| 推荐排序 | 系统推荐排序（默认） |
| 价格排序 | 按票价从低到高 |
| 时间排序 | 按出发时间排序 |
| 耗时排序 | 按飞行时长排序 |

#### 航班卡片

每个航班卡片显示以下信息：

- **航空公司：** Logo + 航空公司名称 + 航班号
- **出发信息：** 出发时间（大字）、机场代码、航站楼
- **飞行信息：** 飞行时长、直飞/经停标识、机型
- **到达信息：** 到达时间（大字）、机场代码、航站楼
- **价格：** 最低舱位价格、剩余座位数
- **服务标签：** WiFi、餐食、充电等
- **准点率：** 百分比显示

> 点击航班卡片可展开查看各舱位详情，每个舱位显示行李额度、退改规则和价格，并提供 **"预订"** 按钮。

### 4.2 航班详情页

**路径：** 搜索结果页点击航班卡片，或特价机票卡片

**页面内容：**

#### 航班信息头部

- 航空公司名称和航班号
- 航班日期
- 可视化航线展示：出发时间/机场 → 飞行时长 → 到达时间/机场
- 直飞/经停标识
- 机型、准点率、行李额度、餐食信息

#### 选择舱位

列出该航班所有可用舱位，每个舱位卡片显示：

| 信息项 | 说明 |
|--------|------|
| 舱位名称 | 如 "经济舱"、"公务舱"、"头等舱" |
| 剩余座位 | 可用座位数 |
| 行李额度 | 免费托运行李重量 |
| 退票规则 | 退票手续费说明 |
| 改签规则 | 改签手续费说明 |
| 价格明细 | 票价 + 税费 |
| 总价 | 红色大字显示 |

点击舱位卡片进行选中（蓝色边框标识），首次进入自动选中第一个舱位。

#### 底部操作栏

固定在页面底部，显示：
- 每人应付金额
- **"选择该舱位，填写订单"** 按钮

### 4.3 填写订单

**路径：** 航班详情页选择舱位后点击按钮进入

**页面内容：**

#### 航班摘要

顶部显示航班号、航线、日期、已选舱位和单价。

#### 旅客信息

点击 **"添加旅客"** 可添加多位旅客（根据搜索时设置的人数），每位旅客需填写：

| 字段 | 必填 | 说明 |
|------|------|------|
| 旅客类型 | 是 | 成人 / 儿童 / 婴儿 |
| 姓名 | 是 | 需与证件一致 |
| 性别 | 是 | 男 / 女 |
| 证件类型 | 是 | 身份证、护照、港澳通行证、台湾通行证、其他 |
| 证件号码 | 是 | — |
| 手机号 | 否 | — |
| 邮箱 | 否 | — |
| 出生日期 | 儿童/婴儿必填 | — |
| 常旅客号 | 否 | — |

#### 联系人信息

| 字段 | 必填 | 说明 |
|------|------|------|
| 姓名 | 是 | — |
| 手机号 | 是 | 用于接收订单通知 |
| 邮箱 | 否 | 用于接收电子行程单 |

#### 费用明细

- 票价 × 旅客人数
- 税费 × 旅客人数
- **合计**（红色大字）

#### 提交订单

底部固定栏显示应付总额，点击 **"提交订单"** 按钮创建订单。

> 提交成功后自动跳转到支付页面。订单在创建后15分钟内未支付将自动取消。

### 4.4 SSR特殊服务

在填写旅客信息时，可选择特殊服务需求。

支持的SSR服务：

| SSR代码 | 服务名称 | 说明 | 费用 |
|---------|----------|------|:----:|
| WCHR | 客梯轮椅 | 旅客可上下客梯，但不能远距离行走 | 免费 |
| WCHS | 舱门轮椅 | 旅客能上下客梯，不能走到舱门 | 免费 |
| WCHC | 全程轮椅 | 旅客完全不能行走 | 免费 |
| VGML | 素食餐 | 素食餐食 | 免费 |
| BLML | 清真餐 | 清真餐食 | 免费 |
| CHML | 儿童餐 | 儿童餐食 | 免费 |
| DBML | 糖尿病餐 | 糖尿病专用餐食 | 免费 |
| UMNR | 无陪儿童 | 5-12岁无人陪伴儿童 | ¥200 |
| AVIH | 宠物托运 | 宠物托运服务 | ¥300 |
| BAGG | 额外行李 | 额外托运行李额度 | ¥100 |
| STCR | 担架服务 | 担架服务 | ¥500 |

操作说明：
1. 添加旅客信息时，点击「选择特殊服务」
2. 在弹出的SSR选择面板中勾选所需服务
3. 提交订单后，SSR申请进入待审核状态
4. 订单详情页会显示已申请的SSR列表及状态

### 4.5 支付

**路径：** 提交订单后自动跳转，或从订单详情页进入

**支付流程：**

1. **查看订单摘要：** 订单号、航班信息、旅客姓名、应付金额
2. **注意倒计时：** 页面显示剩余支付时间（黄色提示条），超时订单将自动取消
3. **选择支付方式：**

| 支付方式 | 图标颜色 | 说明 |
|----------|----------|------|
| 微信支付 | 绿色 | 扫码支付 |
| 支付宝 | 蓝色 | 扫码支付 |
| 银行卡 | 蓝色 | 银行卡支付 |
| 信用卡 | 金色 | 信用卡支付 |

4. 点击 **"确认支付 ¥XXX"** 按钮
5. **扫码支付：** 微信/支付宝会弹出二维码，使用对应APP扫码完成支付
6. 支付成功后自动跳转到订单详情页

> 支付页面会自动轮询支付状态，支付成功后自动跳转，无需手动刷新。

## 五、订单管理

### 5.1 订单列表

**路径：** 顶部导航 → 用户头像下拉菜单 → 我的订单

**功能：**

- **状态筛选标签：** 全部、待支付、已支付、已完成、已取消
- **搜索：** 输入航班号或订单号进行搜索
- **订单卡片信息：** 订单号、状态标签、航线、航班号、旅客姓名、总价、下单时间

点击任意订单卡片进入订单详情页。

### 5.2 订单详情

**路径：** 订单列表点击订单卡片

**页面内容：**

#### 状态横幅

根据订单状态显示不同颜色和提示：
- 🟢 已支付/已出票/已值机/已完成：绿色，"客票已出，祝您旅途愉快"
- 🟡 待支付：黄色，"请在 XX:XX 前完成支付"
- ⚪ 已取消/已退款：灰色

#### 航班信息

出发时间/机场/航站楼/登机口 → 航班号 → 到达时间/机场/航站楼

#### 旅客信息表格

| 列 | 说明 |
|----|------|
| 姓名 | 旅客姓名 |
| 证件号 | 脱敏显示 |
| 票号 | 出票后显示 |
| 座位 | 值机后显示，如 "12A" |
| 值机状态 | "已值机"（绿色）或 "未值机"（灰色） |

#### 费用明细

票价、税费、保险费（如有）、行李费（如有）、合计

#### 退改签规则

显示退票规则、改签规则、签转规则。

#### 操作按钮

根据订单状态显示不同操作：

| 按钮 | 显示条件 | 说明 |
|------|----------|------|
| 去支付 | 待支付订单 | 跳转到支付页 |
| 取消订单 | 待支付订单 | 确认后取消订单 |
| 在线值机 | 已支付且在值机时段内 | 跳转到选座页 |
| 申请改签 | 允许改签时 | 弹窗填写改签信息 |
| 申请退票 | 允许退票时 | 弹窗填写退票原因 |

#### 自动改签通知

若原航班被取消且系统已自动改签：
- 订单详情顶部会标注「本订单由原航班XXX自动改签」
- 旅客会收到实时通知弹窗：「您的航班XXX已取消，已自动改签至YYY」
- 通知面板中可查看改签历史

### 5.3 取消订单

**操作步骤：**

1. 在订单详情页点击 **"取消订单"**
2. 弹出确认对话框，点击 **"确定"**
3. 订单状态变为 "已取消"

> 只有待支付状态的订单可以取消。

### 5.4 申请改签

**操作步骤：**

1. 在订单详情页点击 **"申请改签"**
2. 在弹窗中填写：
   - 改签航段索引（默认0）
   - 新航班ID（必填）
   - 新舱位等级（经济舱/公务舱/头等舱）
3. 点击 **"确认改签"**
4. 系统计算改签费用（手续费 + 票价差额），等待审核

### 5.5 申请退票

**操作步骤：**

1. 在订单详情页点击 **"申请退票"**
2. 在弹窗中填写 **退票原因**（必填）
3. 点击 **"确认退票"**
4. 系统计算退票费用，等待审核

> 退票金额将在审核通过后按原路返回，预计1-7个工作日到账。

## 六、在线值机

### 6.1 值机条件

**路径：** 顶部导航 → 在线值机

**值机规则：**
- 航班起飞前 **24小时内** 开放值机
- 起飞前 **45分钟** 关闭值机
- 仅已支付且已出票的订单可办理值机

**页面展示：**

符合值机条件的航班以卡片形式列出，每个卡片显示：
- 航班号和航线
- 值机时间窗口（开放时间 - 关闭时间）
- 出发时间和航站楼
- 旅客列表及值机状态

点击 **"办理值机"** 或 **"继续值机"** 进入选座页面。

> 若无可值机航班，页面显示提示"值机通常在航班起飞前24小时开放"，并提供"查看我的订单"按钮。

### 6.2 选择座位

**路径：** 在线值机页点击办理值机，或订单详情页点击在线值机

**座位图说明：**

| 颜色 | 含义 |
|------|------|
| 🟢 绿色 | 可选座位 |
| ⚪ 灰色 | 已占用座位 |
| 🔵 蓝色 | 当前选中座位 |
| 🟠 橙色 | 出口排座位（可能有额外费用） |

**操作步骤：**

1. 查看座位图，绿色座位为可选
2. **点击** 一个绿色座位进行选中
3. 底部显示选中座位信息（如 "12A"）
4. 若为付费座位，会显示额外费用金额
5. 点击 **"确认选座并值机"** 按钮

> 座位图上方有机头标识，下方有机尾标识，中间列之间有走道间隔。每排座位按 A-B-C（走道）D-E-F 排列。

### 6.3 完成值机

确认选座后，系统自动办理值机：
- 显示 "值机成功！" 提示
- 跳转到订单列表页
- 订单详情中旅客的值机状态更新为 "已值机"，座位号显示选中的座位

## 七、航班动态

航班动态页包含两个子 tab：「单班查询」与「机场大屏」。

### 7.1 查询航班状态

**路径：** 顶部导航 → 航班动态

**操作步骤：**

1. 输入 **航班号**（如 "CA1234"）
2. 选择 **日期**（默认今天）
3. （可选）输入出发地和到达地进行精确查询
4. 点击 **"查询"**

**查询结果包含：**

#### 状态标签

| 状态 | 颜色 | 说明 |
|------|------|------|
| 已计划 | 灰色 | 航班正常排期 |
| 值机中 | 蓝色 | 正在办理值机 |
| 登机中 | 蓝色 | 旅客正在登机 |
| 已起飞 | 绿色 | 航班已起飞 |
| 飞行中 | 绿色 | 航班正在飞行 |
| 已到达 | 绿色 | 航班已到达目的地 |
| 延误 | 黄色 | 航班延误 |
| 备降 | 黄色 | 航班备降其他机场 |
| 返航 | 黄色 | 航班返航 |
| 取消 | 红色 | 航班已取消 |

#### 航线信息

- 出发：计划时间、预计时间（延误时红色显示）、机场名称、航站楼、登机口
- 航线图示：带飞行中动画效果
- 延误信息：延误时长和原因
- 到达：计划时间、预计时间、机场名称、航站楼

#### 航班时间线

按时间顺序显示航班事件（如"值机开始"、"开始登机"、"预计起飞"等）。

### 7.2 订阅航班动态

在查询结果页面下方，可订阅航班动态推送：

1. 选择推送渠道（至少选一个）：
   - ☑ 短信
   - ☐ 邮件
   - ☐ 推送
   - ☐ 微信
2. 点击 **"订阅"** 按钮

订阅后，当航班发生以下状态变更时会收到通知：
- 延误（DELAY）
- 登机口变更（GATE_CHANGE）
- 开始登机（BOARDING）
- 取消（CANCEL）

### 7.3 机场大屏

**路径：** 顶部导航 → 航班动态 → 「机场大屏」tab

在「机场大屏」tab 中可查看机场的航班信息大屏（FIDS）：

1. **选择方向：** 切换「出发」/「到达」，分别查看从该机场出发或抵达该机场的航班
2. **选择机场：** 从机场下拉框选择要查看的机场
3. **选择日期：** 默认当天，可切换日期
4. **搜索航班号：** 输入航班号快速过滤

大屏以深色表格展示：航班号、航空公司、目的地/始发地（城市·机场名）、计划时间、实际时间、登机口（出发方向）和状态（延误/取消以颜色区分）。页面实时时钟每秒刷新，航班数据每 30 秒自动刷新。

#### 删除旅客

点击旅客卡片上的 **"删除"** 按钮，确认后删除。
